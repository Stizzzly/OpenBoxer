The independent semantic core is clip.cpp; owner/model layout and preserved callback ABI are in clip_layout.hpp. Selection rereads the stored signed bound, preserves the original requested pointer, selects the first comparator zero, looks up again after the selector write and copies frame/factor/live clock in the required order. The original comparator is preserved in native and differential routes.

The guarded adapter accepts only the registered global lower owner and three approved gameplay caller roles. Unsupported state forwards to the original before selection effects. Strings are checked read-only through bounded256-byte readability queries; no guard comparator call decides a match. Diagnostics/captures/isolation default off. Optional native capture records the first two supported calls per verified stand/run/backward caller, at most six total.

--clip-fixture and --clip-replay are distinct from existing light-selection modes. OPENBOXER_CLIP_MODE selects the route; OPENBOXER_CLIP_REPLAY_LIST supplies semicolon-separated typed captures. The optional observer synthesizes the approved complete comparator CALL from metadata and forwards the original comparator body. Ordinary launch leaves that CALL unchanged. Fixture mutation cases cover live bound/request/selector/collection/start/clock effects, different second lookup records and raw clock patterns. Offline ASCII comparison is only a fixture dependency; original-process cases use the preserved original comparator.
