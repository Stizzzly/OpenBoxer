# ANIM-0004 activation extension

Authority: `specs/animation/ANIM-0004-strike-block-selection.md`. This extends the existing ANIM-0002 selector adapter for seven confirmed actor0 strike/block routes. No twelfth semantic core, upper model or gameplay decision implementation is introduced. Eleven prior semantic cores remain byte-identical.

New routes require exact caller, module literal pointer and terminated literal bytes, registered owner+644 lifetime and the existing collection/frame/time safety checks. Unsupported new routes forward to original before selector effects. Existing movement/idle activation retains its previously validated fallback; strict action identity governs new routes and idle action capture only.

`OPENBOXER_ACTION_MODE` controls new action routes independently of `OPENBOXER_CLIP_MODE`; absent override inherits ordinary replacement mode. `OPENBOXER_CAPTURE=action` records the first two calls per new role and idle (maximum16). Ordinary launch performs no new capture I/O and leaves comparator callsite unchanged. Optional action capture uses the existing comparator metadata seam and forwards shared lookup events when the frames recorder is also installed.

Each successful captured selector establishes a thread-local pending witness containing model, selector, frame, anchor and collection bounds. The next admitted same-model frames call must match those witnesses; intervening selectors, unsupported/mismatched frames and reentrancy discard correlation. The capture records frames/advancement counter deltas, pre/prepared/post model state, selected record, clock, EAX and FP witnesses. `action-composed.jsonl` joins selector sequence/state to frames sequence and the named `action-pose-*.bin` artifact. Pose binaries use unchanged FRM3 version1, accepted by `--frames-replay`; selector binaries use unchanged CLP2 version1.

`--action-fixture <absolute DLL>` runs all24 existing selector cases plus eight typed real-name/data cases. `--action-replay <absolute DLL>` consumes `OPENBOXER_ACTION_REPLAY_LIST`, at most16 semicolon-separated captures. Both workers are disposable original-process harnesses executed only by root. Their reports are `action-fixtures.jsonl` and `action-replays.jsonl`. Offline tests cover32 cases and identity rejection for all seven new roles, retaining exact full state/return/callback/FP and ABI policies.

Implementation verification: Clang x86 build and14 CTests pass; eleven core hashes match `validation/ANIM-0004-prior-core-hashes.json`. Original differential and natural per-role validation remain the independent validator/root responsibility. Missing natural roles must remain BLOCKED.
